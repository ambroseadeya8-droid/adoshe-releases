# ADOSHE Releases

Official release and update source for the ADOSHE Accounting System desktop application.

## Release policy

- Stable releases use semantic version tags such as `v3.2.0`.
- Windows x64 NSIS installers and portable builds are published as release assets.
- ADOSHE desktop clients use this repository as their official update source.
- Business data is stored locally by the application and is not published here.
